# AgentDeck Focus 暖白工作台界面设计

## 目标

移除当前的黑色科幻视觉，将本地 Codex 任务控制台改为温和、克制且适合每天使用的开发工具。保留现有项目、任务、Worktree、人工接管和 Git 审查能力；不改变 API、状态机或本地安全边界。

## 视觉系统

- 画布：暖灰 `#f5f3ef`，避免纯白刺眼和深色终端感。
- 内容层：白色或浅米色面板，细暖灰边线，4–6px 圆角。
- 文字：石墨 `#25262a`；路径和 SHA 使用等宽字体。
- 强调色：墨蓝用于主要操作；鼠尾草绿、琥珀、砖红只用于状态和风险。
- 密度：用表格、分隔线和清晰分组组织信息，避免大号标题和空旷展示区。

## 布局

- 左侧为浅色项目导航；顶部展示当前项目、Git 状态与新建任务入口。
- 项目页使用项目摘要、紧凑命令中心和任务表格。运行模式保持分段控件，并以明确文字说明隔离 Worktree 不会直接修改主工作区。
- 任务页保持多面板：主列用于人工确认与 Diff，侧列用于 Worktree 元数据和活动流。危险清理操作保持醒目的前置条件说明。

## 可访问性与响应式

- 保留所有表单标签和现有可访问名称，按钮保留清晰状态。
- 焦点状态使用可见深蓝描边；色彩不是唯一状态信号。
- 窄屏下侧栏改为项目条，命令中心纵向排列，审查区从双栏回退到单栏。

## 验证

- 更新 Playwright 对非 Git 禁用态、人工输入、审查、失败/清理和窄屏的界面断言。
- 在浏览器中检查首页、项目页、任务详情页和窄屏页面。
- 运行 `npm test`、`npm run lint`、`npm run build` 与 `npx playwright test`。
